# physis

Physis is planned as a local-first, generative, AI-assisted digital art
installation. An older Linux laptop will render the artwork continuously and
serve a lightweight control interface to trusted devices on the local network.

The project is currently in the documentation and setup phase. There is no
application implementation yet.
