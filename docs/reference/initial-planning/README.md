# Initial AI planning conversation

This folder preserves notes from the project's initial AI conversation:

- `ai_art_architecture.md` – early artwork and system architecture notes
- `ai_dev_options.md` – early development and technology options
- `gh_setup.md` – initial GitHub setup notes
- `linux_os.md` – presentation-laptop operating-system notes
- `system_spec.md` – recorded hardware and system information

These files are historical reference only. They are not the current project
requirements or instructions for agents. Current guidance belongs in `AGENTS.md`
and curated project documentation belongs in `docs/`. When this reference
conflicts with current documentation, current documentation wins.
